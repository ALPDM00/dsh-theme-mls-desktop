### 「主题设置」页（设置对话框里那一个 nav cell）

| 控件 | 语义 |
| --- | --- |
| **每轮 Token 结算** 开关 | 独立开关，**默认开启** —— 关掉就不再贴结算纸条、已有的立刻摘掉、也停止轮询计费接口（见 [docs/BILLING.md](BILLING.md)）。⚠️ 纸条**不跟主题色走**：它永远用最初那支酸绿（`--mar-bill-accent` / `-ink` / `-acid`），换主题色只影响界面 chrome |
| **任务完成动画** 开关 | 独立开关，**默认开启** —— 一轮正常结束时播放四拍收尾动画（见下）；关掉即不订阅会话快照、不建节点、不留定时器 |
| **完成文案** + 预览 | 绿色横幅上那行字，默认 `//RUN_COMPLETE`，可改成任意文本（≤48 字）；「预览」立刻重播一次（忽略开关本身，但仍尊重系统「减少动态效果」，并把原因写在那行小字里）。下面一行小字是**触发状态**：已挂上会话订阅 / 等待 sessions 服务 / 已关闭 |
| **背景动画** 开关 | 独立开关，**默认关闭** —— 点阵场是可选效果。它不碰配色：关掉只收起场，底盘与强调色停在原地 |
| **启动动画** 开关 | 独立开关，**默认开启**（2026-10-17 新增）—— 冷启动揭幕（鲸鱼 → HUI 框 → 蓝块 → 红扫 → 揭幕）。它**只在下次冷启动生效**（揭幕发生在设置页能打开之前），这一组因此**只有一个开关、没有任何说明行** —— 用户 2026-10-17 明确要求删掉那句解释（"这句话删除掉"）。关掉时若揭幕正好还在跑（装载后几秒内就打开设置），覆盖层会被立刻收掉。存储键 `mar.boot.v1` |
| **浅色 / 深色** | 单指**底盘**的互斥单选（浅色 = 白底黑字，深色 = DSH 原生深色）。不论场开不开都换底盘；换另一个时重放 0.341s 马赛克「灌注」。**不再叫「主白 + 绿 / 主黑 + 绿」**——那两套名字把强调色写进了底盘里 |
| **主题色**（七个色块，一行 4 个） | 七选一的**主题配色**，换的是 UI 强调色（`--mar-accent` 系列）**和背景点阵的字形色**（2026-10-19 起 `bgInk()` 直接读当前主题色；此前点阵被钉在 `192,254,4`）。默认 `#C0FE04`；色块无文本，`aria-label` 里留十六进制值。七格全都有图（见下）。**不受影响**的只有启动入场动画与任务完成动画的用色 |
| 点阵密度 / 透明度 / 呼吸速度 | 只描述点阵场，场关闭时变暗且 `disabled`，数值保留。**透明度**（2026-10-19 新增，0–100%，默认 100%）乘在每条字形的 alpha 上：100% 就是原来的强度，0% 完全看不见（拖动即时重画当前帧） |

**色块上的图案**：`assets/factions/*.svg`，七张 366:237 的矢量重绘，构建时按
`data-accent` 生成 `.mar-sw button[data-accent="#xxxxxx"]{--sw-img:url("data:image/svg+xml,…")}`
内联进 `client.js`（映射表在 `scripts/build.cjs` 的 `FACTIONS`）。对应关系：

| 色块 | 图案 | 图形自己的底色 |
| --- | --- | --- |
| `#05C938` | 赛博艾克米（阵营） | `#00CB36` |
| `#E60B10` | 阿拉克尼（阵营） | `#E80B0E` |
| `#E7337C` | 纽卡洛里（阵营） | `#E9357E` |
| `#E5710C` | 特莱克斯（阵营） | `#EA710B` |
| `#C272E9` | 米达（阵营） | `#C374EA` |
| `#81E8B1` | 关口（阵营） | `#81E8B1` |
| `#C0FE04` | **马拉松 LOGO**（默认色） | `#C0FE04` |

六个阵营 + 默认色的马拉松 LOGO，**七格全部有图**（默认色那一格 2026-10-16 补上，
此前它是唯一的纯色格）。六个阵营图形的底色与调色板取值有细微差异（两批是分别做的），
**以调色板为准**——那才是 UI 真正穿上的颜色；马拉松 LOGO 那张的底色本来就正好是 `#C0FE04`。
想换图 / 加图：把 SVG 放进 `assets/factions/`、在 `build.cjs` 的 `FACTIONS`
里加一行 `['<HEX>', '<文件名>']`，重新构建即可。生成的那条规则**必须是一行、且不含裸的
单引号 / 反斜杠**：它落在模板样式表里一个单引号 JS 字符串里面，破坏它会让整个 bundle 变成
语法错误（`.generated/verify-accent.cjs` 与 `check.cjs` 都盯着这条）。

「外观」下的浅色 / 深色与它**下方独立成组的「主题色」是两件事**：前者决定白底还是黑底，
后者决定强调色（会话选中行 / 发送按钮 / focus 环 / 设置页自己的高亮）。强调色的墨色是
**量出来的**：`#E60B10` 这类偏暗的颜色会拿到白墨（`--mar-accent-ink` / `--mar-solid-ink`
一起翻），其余是原来的 `#0B0D0B`。在浅色底盘上强调色永远只做**面**不做**字**
（`--mar-accent-text` 取主墨色），与旧规则一致。

控件结构与文案与网页版 `dsh-theme-marathon` 原本逐字节相同；**2026-10-11 起桌面版多出
「主题色」这一组**（七个色块 + 强调色状态），网页版还没有。存储键沿用
`dsh-theme-marathon.bg.v1`；配色存在自己的键 `dsh-theme-marathon.accent.v1`
（单个十六进制字符串，大小写会被归一化；不在那七个里的值读回默认）。0.2.0 起
`bg` 键存的形状从 `{mode, scheme, cell, speed}` 变为 `{anim, scheme, cell, speed}`；
旧形状读取时自动迁移（`mode: off` → `anim: false` 并保留它的 `scheme`，
`mode: light|dark|green` → `anim: true` + 那一对底盘）。
「每轮 Token 结算」与「任务完成动画」是另外两个独立开关，各有自己的存储键
（`mar.billing.v1` / `mar.done.v1`），与底盘那一对互不影响。

### 配色切换动画（预留接口）

用户 2026-10-11：「在切换颜色时，也需要有一个动画，我们先预留动画接口」。接口已经留好，
**目前是空实现**——点色块即时生效、不播动画：

```js
// src/client.template.js
function accentSwitchFx(next, apply) {   // next = 要切到的颜色，apply = 唯一的状态变更
  if (typeof apply === 'function') apply();
}
```

契约：动画必须**恰好调用一次** `apply()`（就是 `accentApply`），并且同步地从动画播放器里调用。
现成的 `vtPour(apply)`（马赛克「灌注」的 View Transition 播放器）就是同一个形状，想复用直接
把 `accentApply` 传进去即可。点色块的路径只认这一个入口——不要在它旁边再补一次 `accentApply()`。

## 设置页与调参位置

**设置页（设置 ›「主题设置」）按功能分成六组**，每组一个带色块与横线的大标题
（用户 2026-10-10："需要有一个大标题来区分功能"，并参考了同类的 endfield 主题）：

| 分组 | 里面有什么 |
| --- | --- |
| **外观** | 配色（浅色 / 深色 单选，底盘）—— 只有两个词，没有预览图案（用户 2026-10-17），并且**不被"关闭背景动画就变暗"那条规则连坐**（加了 `.mar-set-appearance`；那 45% 的暗就是用户说的"像有一层灰黑色蒙住了"） |
| **主题色** | 七个 366:237 的色块、一行 4 个（主题配色 / UI 强调色，互斥单选，默认 `#C0FE04`）——用户 2026-10-11："外观的下方添加配色……一共七个配色，不需要文本，让用户点击即可"；2026-10-17 标题由「配色」改名「主题色」，图形放大到一行 4 个 |
| **背景动画** | 启用开关 + **它自己的三项参数（点阵密度 / 透明度 / 呼吸速度）紧跟在下面** —— 关掉时这三行会变暗并禁用（以前开关和参数之间隔着整个"任务完成动画"分组，用户反馈"离得太远"） |
| **启动动画** | 启用开关（只有一个开关，没有说明行）—— 2026-10-17 新增；它**只在下次冷启动生效**，揭幕发生在设置页能打开之前 |
| **任务完成动画** | 启用开关 + 完成文案 + 预览按钮 + 两行小字（预览反馈 / 触发状态与最近一次判定） |
| **每轮 Token 结算** | 启用开关 |

组内行距 10px、组间 24px；小字与输入框左对齐（124px = 标签列 + 间隙）。
改结构就改 `src/client.template.js` 的 `buildPane()` 与 `.mar-set-*` / `.mar-set-head` 那组 CSS；
开发期的自检里有断言盯着"分组标题的顺序"与"开关紧贴它的参数行"，改顺序时别把它们改乱。
⚠️ 往 `buildPane()` 里加**普通 `.mar-set-row`**（不是开关行）时要想清楚：`.mar-anim-off` 那条规则会把
除 `.mar-set-switch` / `.mar-set-done` / `.mar-set-appearance` / `.mar-set-boot` 之外的行调到 45% ——
凡是"与点阵场无关"的行都要进那个排除名单，否则就会看起来像蒙了一层灰。
