## 议题 #3 —— 提问卡片被清成透明（以及分发素材）

提问卡片被清成透明已修，0.5.4 起生效：背景动画的清底扫描不再进入输入卡座位内部，
卡片即使比 200×200 大也保留自己的底色，另外还有一层 CSS 兜底，旧节点带着标记被复用也不会透。
关于「分发包素材乱码、还缺一张 SVG」：我们核实了仓库，`assets/factions/` 下七个文件齐全 ——
`马拉松LOGO.svg` / `赛博艾克米.svg` / `阿拉克尼.svg` / `纽卡洛里.svg` / `米达.svg` /
`特莱克斯.svg` / `关口.svg`，文件名是正常 UTF-8，本机 `node scripts/build.cjs` 也成功；
会出现乱码或"缺一张"的只有取包通道不是 UTF-8 的情况（非 UTF-8 locale 的 `git clone`，
或者某些镜像重新打包 tarball 时只保留 ASCII 文件名）。请用 GitHub 官方 zip / tarball 重新取一次；
或者让 git 明确走 UTF-8（`git config --global i18n.logOutputEncoding utf-8`、`core.quotepath false`），
并在 UTF-8 代码页下解压。另外 0.5.4 起构建改成先按 SVG 自带的 `<title>` 找图，即使检出把文件名写坏，
`npm run build` 也不会再报缺图，只在结尾打一行警告提醒去修检出。升级后重启桌面端
（0.5.4 改了壳补丁 revision，先按上面的须知跑一次 `--repair` 再重启）；
`link:` 安装的记得先重新构建。

`--repair` 再重启）；`link:` 装法先 `npm run build`。

## 议题 #5 —— 热重载后整页文字不可见

已修，0.5.4 起生效。根因是揭幕的阶段标记 `html[data-mar-boot]` 在热重载时留了下来
（同一页面再跑一次 `apply()`，旧实例没走完 dispose），而样式表把这条属性翻译成
「body 下所有元素 `visibility:hidden`」；遮罩宿主已经不在，于是整页只剩背景。
现在 `apply()` 入口会无条件、幂等地摘掉这个属性，属性只在遮罩宿主确实挂进 DOM 之后才写，
另外还有 8 秒兜底：宿主仍不在就直接摘掉。
升级后重启桌面端即可（0.5.4 改了壳补丁 revision，先按上面的须知跑一次 `--repair` 再重启）；
如果你还卡在那个状态，可以先在控制台执行
`document.documentElement.removeAttribute('data-mar-boot')` 救急。
